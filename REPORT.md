## 1. Введение

### 1.1. Актуальность
Автоматизированное прогнозирование финансовых временных рядов является одной из наиболее востребованных задач в сфере Data Science. Несмотря на высокую волатильность рынков и наличие случайного шума, применение методов машинного обучения позволяет выявлять скрытые паттерны в исторических данных, что может служить основой для принятия инвестиционных решений.

### 1.2. Цель работы
Разработка и исследование моделей машинного обучения для бинарной классификации направления движения цены акции Apple (AAPL) на горизонте 5 торговых дней.

### 1.3. Задачи
1. Сбор и очистка исторических котировок за 5 лет (дневной таймфрейм).
2. Проведение разведочного анализа данных (EDA).
3. Инженерия признаков (Feature Engineering): расчёт технических индикаторов.
4. Обучение и сравнение нескольких алгоритмов (Baseline).
5. Подбор гиперпараметров для улучшения метрик (Tuning).
6. Разработка интерактивного веб-приложения для демонстрации работы модели.

## 3. Описание процесса исследования

### 3.1. Данные
*   **Инструмент:** AAPL (Apple Inc.)
*   **Период:** 5 лет (с 2021 по 2026 год).
*   **Таймфрейм:** 1 день (Daily).
*   **Объём:** 1255 записей, после очистки и расчёта лагов — 1156 записей.
*   **Целевая переменная:** Бинарный класс. `1` — цена закрытия через 5 дней выше текущей, `0` — иначе.

### 3.2. Feature Engineering (Создание признаков)
Для повышения предсказательной силы моделей были сгенерированы следующие признаки:
1.  **Лаги (Lags):** Цены и объёмы за последние 1, 2, 3, 5, 10, 20 дней.
2.  **Скользящие средние (MA):** Трендовые линии за 5, 10, 20, 50, 100 дней и отклонение цены от них.
3.  **RSI (Relative Strength Index):** Индекс относительной силы для выявления зон перекупленности/перепроданности.
4.  **MACD:** Индикатор схождения/расхождения скользящих средних.
5.  **Bollinger Bands:** Полосы волатильности.

### 3.3. Обучение моделей
Использовалось **хронологическое разделение** (80% обучение / 20% тест), чтобы избежать утечки будущего в прошлое.

Протестированы модели:
1.  Logistic Regression (Линейная модель)
2.  SVM (Метод опорных векторов)
3.  Decision Tree (Дерево решений)
4.  Random Forest (Ансамблевый метод)
5.  Gradient Boosting (Ансамблевый метод)

**Оптимизация:** Для Random Forest и Gradient Boosting применялся `GridSearchCV` для подбора оптимального количества деревьев, глубины и скорости обучения.

## 4. Результаты и анализ

### 4.1. Метрики качества
После обучения и подбора гиперпараметров были получены следующие результаты:

| Модель | Accuracy | F1-Score | ROC-AUC |
|--------|----------|----------|---------|
| Logistic Regression | 0.513 | 0.553 | 0.503 |
| Random Forest (Tuned) | 0.461 | 0.183 | 0.607 |
| Gradient Boosting (Tuned) | 0.461 | 0.242 | 0.581 |

### 4.2. Интерпретация результатов
1.  **Низкий ROC-AUC (~0.6):** Модели лишь незначительно превосходят случайное угадывание (0.5). Это согласуется с **Гипотезой эффективного рынка (EMH)**: текущая цена уже содержит всю публичную информацию, и предсказать её на основе только истории крайне сложно.
2.  **Высокая Precision, низкий Recall:** Ансамблевые модели (RF, GB) научились быть "консервативными". Они редко выдают сигнал на покупку (низкий Recall), но когда выдают — вероятность успеха выше (высокая Precision). Это может интерпретироваться как стратегия управления рисками.
3.  **Сравнение алгоритмов:** Простые линейные модели (SVM/LR) показали более стабильные результаты по F1, чем сложные ансамбли, что говорит о том, что в данных много шума, который сложные модели пытались "запомнить" (переобучение).

## 5. Описание веб-приложения (Streamlit)

Разработан интерфейс для демонстрации работы алгоритмов с возможностью интерактивного взаимодействия.

**Ключевые функции:**
1.  **Интерактивный график:**
    *   Отображение последних 1000 дней в виде японских свечей.
    *   Автоматический перевод времени в Московский часовой пояс.
    *   При наведении на свечу (Hover) отображается процент изменения цены (зелёный для роста, красный для падения).
    *   **Масштабирование:** Растяжение/сжатие графика по вертикали колесиком мыши (аналог профессиональных терминалов).
2.  **Панель управления моделью:**
    *   Пользователь может изменять гиперпараметры Gradient Boosting (`n_estimators`, `max_depth`, `learning_rate`) в реальном времени.
    *   При изменении параметров модель переобучается на исторических данных.
3.  **Блок метрик:**
    *   Отображение текущих значений F1-Score и ROC-AUC.
    *   Пояснение для пользователя, что означают эти цифры и к чему нужно стремиться.
4.  **Прогноз:**
    *   Выдача сигнала на +5 дней вперёд с указанием вероятности события.

## 6. Заключение

В ходе выполнения НИРС был реализован полный цикл исследования задачи машинного обучения в финансовой сфере: от сбора сырых данных до развёртывания веб-приложения.

**Основные выводы:**
*   Предсказание направления цены актива на среднесрочном горизонте (5 дней) с использованием только технических индикаторов является сложной задачей с невысокой предсказательной силой (ROC-AUC < 0.65).
*   Сложные ансамблевые модели требуют очень тщательной настройки и больших объёмов данных, чтобы превзойти простые линейные методы на зашумлённых финансовых рядах.
*   Разработанное приложение успешно интегрирует модель в пользовательский интерфейс, позволяя визуально оценивать влияние гиперпараметров на качество прогноза.

**Перспективы развития:**
Для повышения точности модели в будущем рекомендуется добавить альтернативные данные (новостной фон, макроэкономические показатели) и рассмотреть применение рекуррентных нейронных сетей (LSTM) для работы с временными рядами.
